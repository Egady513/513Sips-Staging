# 513Sips Commercial Keyword Test

Date started: October 2, 2026  
Test surface: Google Search, including Google's generative AI features  
Minimum observation window: 6 weeks after production publishing and confirmed indexing

## Why this is a controlled test

Each commercial page gets one distinct search intent. This prevents the homepage and service pages from competing with each other and lets Search Console show whether Google understands the role of each page.

| Page | Primary phrase | Supporting language | Searcher's job |
| --- | --- | --- | --- |
| Homepage | mobile bartending Cincinnati | Cincinnati mobile bartender, event bar service | Find a local service and compare options |
| Weddings | wedding bartender Cincinnati | wedding bar service Cincinnati, mobile wedding bar | Find a specialist who can plan and run the full wedding bar |
| Private Parties | private party bartender Cincinnati | birthday bartender Cincinnati, bartender for private event | Find a bartender for a home, venue or themed celebration |

"Dry hire" stays in supporting copy and FAQs rather than becoming the primary phrase. Searchers often need the model explained before they know the industry term.

## Baseline

Search Console, previous three months at the start of the test:

- 507 impressions
- 49 clicks
- 9.7% click-through rate
- 10.5 average position
- All recorded clicks went to the homepage
- "cincinnati open bar service": 18 impressions, 0 clicks
- "mobile bar cincinnati": 3 impressions, 0 clicks
- Wedding and Private Party pages had not yet appeared in the performance report

## Changes under test

1. Put the primary phrase first in each page title.
2. Give every page a distinct search-result description based on the customer's decision.
3. Preserve the visible emotional headline and Eddie's voice.
4. Connect the homepage's structured service catalog directly to Weddings and Private Parties.
5. Add service, image and breadcrumb context that matches visible page content.
6. Keep first-hand event proof, real photographs and factual FAQs prominent.

## Success measures

Review after indexing, then at weeks 2, 4 and 6:

- Each service page earns impressions for its assigned phrase and close variants.
- Non-brand impressions increase without reducing branded clicks.
- Weddings and Private Parties receive clicks instead of the homepage absorbing every visit.
- Search-result click-through rate holds or improves as impressions grow.
- Qualified visits produce Book Event clicks, inquiry starts and completed inquiries.
- Google's Generative AI performance report begins showing eligible visibility or clicks.

Do not declare a winner from a few days of data. Search indexing and position changes can lag, and local results vary by the searcher's location.

## AI answer visibility

The AI plan is the same evidence-led SEO plan, not a second set of pages:

- Keep pages public, indexable and eligible for snippets on production.
- Answer real customer questions in visible text, not only in structured data.
- Use first-hand event details that a generic competitor or generated article cannot reproduce.
- Maintain consistent facts about service area, insurance, alcohol ownership and procurement.
- Use real event photography with descriptive alternate text.
- Earn authentic mentions and links from venues, planners, caterers and specialty partners.
- Monitor Google's Generative AI report in Search Console.

No `llms.txt` file is included in this test. Google states that it ignores the file for Search ranking and generative AI visibility. There is also no special AI schema required beyond accurate structured data that matches the visible page.
