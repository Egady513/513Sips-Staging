## Live URL and indexation baseline

Observed on 2026-09-23:

| URL | Live behavior | Preferred handling |
|---|---|---|
| `https://513sips.com/` | 301 to `https://www.513sips.com/` | Keep |
| `https://www.513sips.com/` | 200, canonical to itself | Keep |
| `/index.html` | 200, canonical to `/` | Acceptable GitHub Pages alias |
| `/home` | 404 | Restore as a zero-second legacy redirect to `/` |
| `/about` | 404 | Restore as a zero-second legacy redirect to `/#about` |
| `/services` | 404 | Restore as a zero-second legacy redirect to `/#services` |
| `/contact` | 404 | Restore as a zero-second legacy redirect to `/#contact` |
| `/faq` and `/faq.html` | Both 200. Both resolve to the same file, which canonicals to `/faq.html`. | Keep `/faq.html` as the canonical to protect the existing URL. |
| `/gallery` and `/gallery.html` | Both 200. Canonical is `/gallery.html`. | Keep |
| `/blog` | 301 to `/blog/` | Keep |
| `/calculator.html` | 404 but was listed in the production sitemap | Remove from sitemap |
| `/tools/calculator.html` | 200 internal operational tool | Do not add to the public sitemap |

GitHub Pages does not offer repository-level HTTP redirect rules for these static files. The legacy redirect files use the supported fallback of a zero-second meta refresh, a canonical and `location.replace`. A future move behind Cloudflare or another edge layer could replace these with server-side 301 redirects.

Fragments such as `/#about`, `/#services` and `/#contact` are homepage navigation states. They are not separate server resources and should not become separate pages.

## Analytics baseline

No GA4 Google tag, Google Tag Manager container or Microsoft Clarity script was found in the repository or live HTML. There is no existing site-side analytics event layer.

The staging branch now contains a small provider-neutral customer-journey event file. It prepares these useful events without inventing an external ID:

- `book_event_click`

- `email_click`

## Live search and competitor observations

Searches reviewed included `Cincinnati wedding bartender`, `Cincinnati mobile bartending`, `open bar service Cincinnati` and `Cincinnati corporate event bartender`.

Businesses currently appearing for relevant searches include Bars On Wheels, Black Rose Cocktails, On The Rocks Cincinnati, Champagne Sisters, The Bar Cincy, Mane Event Trailer Co., Blonde & Boozy, Bartender With a Smile and Serving It Up. CincySips and Clementine Caravan compete more heavily on visual identity and mobile-bar presentation. Some names in the earlier inventory did not appear prominently in the sampled results and should not automatically be treated as direct organic competitors.

Observed patterns:

- Bars On Wheels has a deep wedding service page with coordination, FAQs, service areas and repeated availability calls to action.
- On The Rocks uses separate pages for weddings, corporate events, private parties and bar setup, plus many city references. Its architecture is broad but much of the copy is generic.
- Black Rose has dedicated wedding and corporate pages with strong owner-led positioning but little visible pricing detail.
- Champagne Sisters presents clear package inclusions and dry-hire options.
- Trailer-led companies have a strong visual product but may solve a different need from bartender-led service.
- 513Sips is unusually clear about starting prices. That is a conversion advantage worth protecting.

The useful whitespace for 513Sips is not more generic copy. It is clarity plus first-hand proof: real guest counts, what the couple buys, what 513Sips handles, actual bar logistics, signature drink details and lessons that reduce surprises.
